Quick start

API

What it does

Kairo describes a process through states computed from a traditional event log, follows how often every state occurs over calendar windows, and turns changes in that mix into drift signals. Every result has a plot_* function for a figure and an abstract_* function for text a language model can read.

Three perspectives

PerspectiveOne row isThe features describe
Intra-casean event its case so far: the activities, their order and the progress
Resourcea calendar window the resources: workload, durations, waits, activity shares and handovers
Inter-casea calendar window all running cases: arrivals, completions, pace, stalls and case attributes

The pipeline

Features → scaling → PCA → states (SOM, k-means or DBSCAN) → trajectories → drift signal. Scaling and PCA can be skipped.

Installation

Kairo ships inside the thesis repository.

From the repository root, this installs kairo as an editable package, so import kairo works in the notebooks and the dashboard:

uv sync

The dashboard starts from its folder:

cd dashboard
uv run streamlit run app.py

API keys

For hosted models, put the key into a .env at the repository root and load it with load_dotenv(). Local servers such as LM Studio or vLLM need none.

ANTHROPIC_API_KEY=...
OPENAI_API_KEY=...
GOOGLE_API_KEY=...

Quick start

Log in, states out, question answered.

Intra-case states

import os
import pandas as pd
import kairo

log = kairo.read_log("log.xes", resource="org:resource", event_duration="event:duration_min")

features = kairo.compute_features_intra(log, sliding_window_size=1)
scaled = kairo.standardize(features, method="minmax")
pca = kairo.compute_pca(scaled, num_components=30)
compressed = kairo.apply_pca(scaled, pca, cut_component=10)

kmeans = kairo.compute_kmeans(compressed, k=5)
states = pd.concat([compressed, kairo.get_kmeans_clusters(compressed, kmeans)], axis=1)

distributions = kairo.compute_state_distributions(states, window="7D")
divergences = kairo.compute_divergences(distributions, divergence="kl", reference="previous")
kairo.plot_divergences(divergences, "kl", "previous").show()

Resource and inter-case states

One row per calendar window, the rest of the pipeline stays the same. The log follows one trajectory through the states, and the windows' vectors can be compared directly.

features = kairo.compute_features_resource(log, window="1D")
# or: kairo.compute_features_inter(log, window="1D", case_attributes={"case:amount": "numerical"})

# scale, PCA and k-means as above, then
trajectory = kairo.get_kmeans_log_trajectory(states)
kairo.plot_kmeans_log_trajectory(trajectory, kairo.compute_kmeans_color_mapping(5)).show()

distances = kairo.compute_window_distances(compressed, distance="euclidean", reference="previous")

Ask a model

tokens, messages = kairo.count_input_tokens(
    "anthropic", kairo.DEFAULT_SYSTEM_PROMPT,
    [kairo.abstract_divergences(divergences, "kl", "previous"), "Where does the process drift?"],
    [kairo.plot_divergences(divergences, "kl", "previous")],
)

llm = kairo.LLMConnector("anthropic", "claude-sonnet-5", api_key=os.environ["ANTHROPIC_API_KEY"])
response = llm.call(messages=messages, max_tokens=16000)
print(kairo.get_response_text(response))

Logs

FunctionReturns
read_log(path, case_id, activity, timestamp, event_id=None, start_timestamp=None, resource=None, event_duration=None) An XES or CSV log with the given columns renamed to kairo's names.
compute_log_stats(log)A dict of counts, throughput times and case lengths.

Features

A DataFrame with the feature columns, named group:name, next to time:timestamp, and for intra-case also case:concept:name. A missing column a picked feature needs raises a ValueError.

FunctionFeature groups
compute_features_intra(log, features, sliding_window_size=0) One row per event: act_freqs, df_counts, act_set, case_progress, current_act, past_acts.
compute_features_resource(log, window="1D", features, resources=None) One row per calendar window: res_events, res_cases, res_durations (needs an event duration), res_waits, act_res_shares, handover_shares. resources picks the columns, None keeps all.
compute_features_inter(log, window="1D", features, case_attributes={}, stall_threshold="1D") One row per calendar window: active_cases, new_arrivals, completions, events_per_case, mean_delta_t, std_delta_t, stalled_cases, attr_means, attr_stds, attr_shares. case_attributes maps a column to "numerical" or "categorical".

A window is a pandas frequency such as "12h", "1D" or "7D". Leaving out features computes all of them.

Scaling and PCA

FunctionReturns
standardize(feature_matrix, method, exclude=["current_act", "past_acts", "act_set"]) The features scaled by "zscore" or "minmax", the excluded groups untouched.
compute_pca(feature_matrix, num_components=None)A fitted sklearn PCA.
apply_pca(feature_matrix, pca, cut_component)The first cut_component components, pc_1 on.

States

FunctionReturns
compute_som(df, size=(5, 5), learning_rate=0.5, distance="euclidean"), get_som_winners(df, som)A MiniSom, then the cell i, j of every row.
compute_kmeans(df, k=5), get_kmeans_clusters(df, kmeans) A fitted KMeans, then the cluster of every row.
compute_dbscan(df, eps=0.5, min_samples=5, distance="euclidean"), get_dbscan_clusters(df, dbscan)A fitted DBSCAN, then the cluster of every row, -1 for noise.
get_*_state_frequencies(df, start_date=None, end_date=None)Rows per state between the dates.
get_som_state_distances(som, distance), get_kmeans_state_distances(kmeans), get_dbscan_state_distances(dbscan)The distance between every two states.
compute_som_color_mapping(size), compute_kmeans_color_mapping(k), compute_dbscan_color_mapping(dbscan)A color per state, shared by all plots.

The distances are euclidean, cosine, manhattan and chebyshev. df is the clustering's input with its states joined on.

Trajectories and drift

FunctionReturns
get_*_case_trajectory(df, case_id)The visits of one case through the states.
get_*_trajectories(df, start_date=None, end_date=None, max_cases) The visits of every case that starts and ends between the dates.
get_*_log_trajectory(df, start_date=None, end_date=None) Resource and inter-case: the log's visits, window by window.
compute_state_distributions(df, window="7D")The share of every state per calendar window.
compute_divergences(distributions, divergence="kl", reference="previous", lookback=5) A score per window: kl, js, tv or hellinger against the previous window, the recent mean or the baseline.
compute_window_distances(df, distance="euclidean", reference="previous", lookback=5) Resource and inter-case: a score per window, the distance of its vector to the reference.
