\chapter{Evaluation}
\label{chap:eval}

\begin{itemize}
	\item Goal: show where the framework is strong and where it has limitations.
	\item Interpret the results from the point of view of the states: what the states give us and what not.
	\item Short notes in the sections and subsections, referenced later in Chapters~\ref{chap:discussion} and~\ref{chap:conclusion}.
\end{itemize}

Evaluation framework (Figure~\ref{fig:eval:example}):
\begin{itemize}
	\item \emph{Runs:} A run reports for each log and each evaluated perspective one configuration and one threshold $\tau$ on its drift scores. We evaluate two runs separately and compare their results.
	\item \emph{Signal windows:} The signal window is the unit of the evaluation. Signal windows without a reference, the partial first and last signal windows and thin signal windows with less than a quarter of the median number of rows are not scored.
	\item \emph{Detection:} A sequence of consecutive signal windows with a drift score of at least $\tau$. It is located at its first signal window.
	\item \emph{Truth event and zone:} An injected drift is a truth event of the perspective that is expected to catch it. Its zone is the signal window of the drift point $\pm 1$ signal window for a sudden drift and the signal windows from its start to its end $\pm 1$ signal window for a gradual drift.
	\item \emph{Counts:} A truth event is a TP if its zone contains at least one detection, otherwise an FN. Each detection outside a zone is an FP, and further detections in a zone are ignored. Each scored signal window outside the zones without a detection is a TN. A perspective without a truth event has no zone, so each of its detections is an FP.
	\item \emph{Metrics:} We sum the counts of all logs of a run and compute precision, recall and F1.
\end{itemize}

Dashed lines mark the drift point of the sudden drift and the start and end of the gradual drift. The zones (blue) add one signal window on both sides. Triangles mark detections, i.e., the first signal window of each sequence of signal windows with a drift score of at least $\tau$. The detection in signal window~4 makes the sudden drift a TP, and the detection in signal window~6 is ignored. The gradual drift has no detection in its zone and is an FN. The detection in signal window~8 is an FP. Signal window~9 continues its sequence and, like all other scored signal windows outside the zones, is a TN. \section{Padella Benchmark}
\label{sec:eval:padella}
\begin{itemize}
	\item Introduce the Padella benchmark~\autocite{padella2026everything}: five real base logs, their five baselines without drift and 29 logs with one injected drift each.
	\item Drift types \texttt{cf}, \texttt{time\_fast} and \texttt{time\_slow}, each sudden and gradual. The baselines are not stationary, so FPs are possible.
	\item Expected perspective of each drift type (Figure~\ref{fig:eval:padella:perspectives}). We evaluate only the intra-case and the resource perspectives.
	\item Global results of both runs first (Figure~\ref{fig:eval:padella:confusion} and Table~\ref{tab:eval:padella:metrics}), then the results per drift type and per drift mode.
	\item The two runs show how much the results of a log depend on its configuration and hyperparameters.
	\item Note: strengths, limitations and what the states show here, for Chapters~\ref{chap:discussion} and~\ref{chap:conclusion}.
\end{itemize}
