Driftify

Synthetic XES event-log generation with known concept drift metadata. Driftify creates logs for control-flow, resource, inter-case, and data-perspective experiments.

Quick start Scripts Drift types Subtypes Parameters Config Output

Quick Start

Edit the constants at the top of a generator script, then run it from the repository root.

uv run python scripts/generate_resource_log.py
uv run python scripts/validate_log.py data/resource/resource_001.xes

Each generated log includes machine-readable metadata in XES log attributes and a human-readable sidecar summary.

Generator Scripts

generate_control_flow_log.py

Changes the process tree. Use this for activity, variant, and ordering drift.

generate_resource_log.py

Changes resource assignment, workload, handover behavior, active pool size, or service speed.

generate_inter_case_log.py

Changes case arrival behavior, burstiness, case mix, or emergent concurrency.

generate_data_log.py

Changes case-level numeric and categorical attributes.

generate_multi_perspective_log.py

Combines multiple perspectives. Add perspective to each drift entry.

Drift Types

Type Behavior Optional parameters
sudden Hard switch at change_point. None.
gradual_linear or gradual Old and new behavior overlap. Probability of new behavior rises linearly. Transition width uses GeneratorConfig.gradual_overlap_fraction, default 0.10.
gradual_exponential Old and new behavior overlap. New behavior starts slowly and rises faster near the end. Transition width uses GeneratorConfig.gradual_overlap_fraction, default 0.10.
incremental Creates intermediate versions and moves through them during the transition window. num_versions: integer, clamped to 3-5. Default: random 3-5.
recurring Alternates between old and new behavior for a finite period, then keeps the new behavior. period_days: length of one recurrence phase. Default uses GeneratorConfig.recurring_period_fraction, 0.20.

Drift Subtypes

Control Flow

Subtype Effect Optional parameters
tree_mutation Mutates the process tree by adding, deleting, moving activities, and swapping operators. change_proportion: float 0.0-1.0, default 0.25.
intensity: alias used when change_proportion is absent.

Resource

Subtype Effect Optional parameters
reassignment Changes the dominant resource for selected activities while keeping the 80/20 dominance shape. activities: list of activity labels or "all". Default: "all".
workload_distribution Changes event counts per resource by skewing all activity-resource assignment probabilities. resources: list of active resources or "all". Default: "all". Listed resources receive 70% of event assignment probability.
service_time Changes processing speed for selected resources. Multipliers above 1.0 are slower, below 1.0 faster. resources: list of resources or "all". Default: "all".
pool_size Shrinks or expands the active resource pool. Inactive resources are not assigned work. None.
handover Rewires one source resource to a different dominant next-resource target. None.

Inter Case

Subtype Effect Optional parameters
arrival_rate Changes mean inter-arrival time, causing cases to arrive faster or slower. None.
burstiness Switches arrival shape between exponential and bursty bimodal-Pareto behavior. None.
case_mix Changes the distribution of case:case_type. None.
concurrency Records a concurrency drift marker. Concurrency is emergent from arrivals and event durations. None.

Data

Subtype Effect Optional parameters
numeric Changes the mean and standard deviation of case:amount. None.
categorical Changes the distribution of case:region. None.

Drift Entry Parameters

Each entry in DRIFTS is a Python dictionary.

Parameter Required Applies to Description
subtype Yes All drifts One of the subtype names listed above.
drift_type No All drifts sudden, gradual_linear, gradual_exponential, incremental, or recurring. Default: sudden.
change_point No All drifts Fraction of the generated horizon, clamped to 0.05-0.95. Example: 0.5 is the midpoint. If omitted, Driftify places drifts within their perspective-specific slots.
perspective Only in multi-perspective scripts Multi-perspective logs control_flow, resource, inter_case, or data. Single-perspective scripts provide a default.
num_versions No drift_type="incremental" Number of versions, clamped to 3-5. Default: random 3-5.
period_days No drift_type="recurring" Length of one recurrence phase. If omitted, Driftify derives it from GeneratorConfig.recurring_period_fraction.
change_proportion No tree_mutation Controls mutation intensity. Useful values: 0.05 subtle, 0.20 medium, 0.50 strong. Default: 0.25.
intensity No tree_mutation Alias for mutation intensity used only when change_proportion is absent. Default: 0.25.
activities No Resource reassignment List of activity labels or "all". Default: "all".
resources No Resource workload_distribution, service_time List of resource ids such as ["res_001"], or "all". Default: "all".

Examples

DRIFTS = [
    {"subtype": "tree_mutation", "drift_type": "sudden", "change_proportion": 0.2},
    {"subtype": "reassignment", "drift_type": "gradual_linear", "activities": ["a", "c"]},
    {"subtype": "workload_distribution", "drift_type": "sudden", "resources": ["res_001", "res_003"]},
    {"subtype": "service_time", "drift_type": "incremental", "resources": "all", "num_versions": 4},
]
DRIFTS = [
    {"perspective": "control_flow", "subtype": "tree_mutation", "drift_type": "sudden"},
    {"perspective": "resource", "subtype": "workload_distribution", "drift_type": "sudden"},
    {"perspective": "inter_case", "subtype": "arrival_rate", "drift_type": "gradual_exponential"},
    {"perspective": "data", "subtype": "numeric", "drift_type": "incremental", "num_versions": 4},
]

Output

Driftify writes an XES log and metadata sidecar.

<output_folder>/<log_name>.xes
<output_folder>/<log_name>.xes.metadata.md

Log Columns

event:id, case:concept:name, concept:name, start_timestamp, time:timestamp, event:duration_min, org:resource, org:role, case:case_type, case:amount, case:region

Metadata

Every drift metadata record contains:

drift_id, perspective, subtype, drift_type, change_point_timestamp, overlap_window_start, overlap_window_end, affected_columns, change_details

The XES file stores JSON strings in log attributes: drift_info, config_info, and noise_info.
